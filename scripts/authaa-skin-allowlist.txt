# freeze manifest. Every on-disk file in src/ios/Views/AuthAA and src/ios/Views/SettingsSkin
# must be either in authaa-freeze-manifest.txt (verbatim) or here (local skin). A new file
# in those dirs that lands in neither set fails the structure assertion -- that is the point.
#
# Row grammar (hardened 2026-09-22 after the adversarial review showed the old
# path-only list was a silent escape hatch):
#   '<local-path>  <sha256 of the file AT REGISTRATION TIME>  <one-line ASCII reason>'
# - The registered sha is re-checked against disk every run: edit the skin file,
#   the gate goes red until you re-register the new sha. Skin changes are legal;
#   UNREGISTERED skin changes are not. Refresh with:
#     sha256sum <path> | cut -d' ' -f1
# - Entry count is capped by ALLOWLIST_MAX in scripts/freeze-check.sh (10 as of
#   2026-09-22). Exceeding the cap is a VIOLATION, not a suggestion.
# - Growing this list (or shrinking the manifest) is a TRANSITION: the gate prints
#   a loud warning and refuses unless FREEZE_ALLOW_TRANSITION=1 accompanies a
#   pp-signed-off commit. Never move a still-verbatim file in here to dodge the freeze.
#
# Group A: skin files deliberately diverged from an upstream counterpart (the
#          counterpart path is named in each row's reason).
# Group B: files with no upstream counterpart at all (our own code).
